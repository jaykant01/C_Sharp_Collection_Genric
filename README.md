## 📘 Description

This repository is created to **deeply understand Collections and Generics in C#**,  
which are **fundamental building blocks** for writing **scalable, reusable, and efficient code**.

The focus is on **concept clarity**, **hands-on examples**, and **interview-oriented practice**,  
organized using a **branch-wise structure**.

---

## 🛠 Tech Stack

- **Language:** C#
- **Framework:** .NET
- **IDE:** Visual Studio
- **Version Control:** Git & GitHub

---

## 🌿 Repository Structure & Branches

### 🔹 `collections` Branch

This branch focuses on **C# Collections Framework** and their practical usage.

**Topics Covered:**
- Introduction to Collections  
- List, ArrayList  
- Dictionary, Hashtable  
- Stack and Queue collections  
- Differences between generic and non-generic collections  
- Real-world usage examples  

**Purpose:**  
To understand how to **store, manage, and retrieve data efficiently**  
using different collection types.

---

### 🔹 `generics` Branch

This branch is dedicated to **Generics in C#**, covered in detail.

**Topics Covered:**
- Why generics are needed  
- Generic classes and methods  
- Type constraints (`where` keyword)  
- Generic interfaces  
- Real-time and reusable coding examples  

**Purpose:**  
To write **type-safe**, **reusable**, and **high-performance code**  
using generics.
